# nwhub

This is a small React/Vite scaffold for the NWDrones internal "Hub" landing page.

Run locally:

```bash
npm install
npm run dev
```

Open http://localhost:5173 and you'll see the Hub. The project includes a collapsible left menu and a center "Bem-vindo" card with app icons rotating around it.

Authentication (Google sign-in) is not implemented here — this is the visual shell only.
